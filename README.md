# 🧮 Mathe Trainer

Mathe-Lernapp für Grundschulkinder mit Sammelkarten-Belohnungssystem.

**[▶️ Jetzt spielen](https://dikri.github.io/GrundrechenartenOneToTen/)**

## Was kann die App?

**Rechenarten:**
- ➕ Addition (1-10, 1-20, 1-100)
- ➖ Subtraktion (1-10, 1-20, 1-100)
- ✖️ Multiplikation (kleines Einmaleins)
- ➗ Division
- 🔀 Mixed-Modi

**727 Sammelkarten in 6 Themes:**
| Theme | Karten | Bilder |
|---|---|---|
| ⚡ Pokémon | 251 | PokéAPI Artworks |
| 💥 Brawl Stars | 106 | Brawlify CDN |
| ⛏️ Minecraft | 90 | Minecraft Wiki |
| 🏎️ Autos | 100 | Wikipedia Fotos |
| 🐾 Tiere | 100 | Wikipedia Fotos |
| 🍄 Super Mario | 80 | MarioWiki Artworks |

**Features:**
- Personalisiert: Name und Lieblings-Alben wählbar
- Sprachausgabe: Aufgaben und Karten werden vorgelesen
- Tages-Statistik mit Streak-Zähler
- Hologramm-Karten mit Dreh-Animation
- Offline-fähig (PWA mit Service Worker)
- Keine Werbung, keine Daten, kostenlos

## Installation

**Im Browser:** Einfach den [Link](https://dikri.github.io/GrundrechenartenOneToTen/) öffnen.

**Als App auf dem Handy:**
- iPhone: Safari → Teilen (⬆️) → "Zum Home-Bildschirm"
- Android: Chrome → Menü (⋮) → "App installieren"

## Technik

Eine einzige `index.html` + JSON-Dateien für die Kartendaten. Keine Dependencies, kein Build-Prozess, kein Backend. Bilder werden von freien APIs geladen und im Browser gecacht.
